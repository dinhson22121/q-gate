Rulebook

Architecture rules derived per repository from its rule files and a code sample.

Rules are derived once per repository from its rule files (CLAUDE.md, ADRs, lint configs) and a code sample, then reused for every commit. Explicit rules start approved; inferred rules start proposed and never block. Rejected rules are never checked. Decisions survive rebuilds. Team rules (added from the Policy assistant) are kept across rebuilds.
