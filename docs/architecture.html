qgate · kiến trúc và luồng dữ liệu

Từ git commit tới gate verdict

Một container Docker trên máy dev theo dõi các repo được mount. Với mỗi commit, qgate kiểm bằng check deterministic, các agent Claude và AC của ticket Jira. Kết quả, cache và config đều nằm trong SQLite ở /data. Sau mỗi lần scan, qgate ghi một file review Markdown để agent của dev đọc và sửa tiếp. LLM không tự quyết định pass hay fail.

Ranh giới tin cậy

  • Repo được phép chọn: model, effort, gate, ignore, [[checks]], ac_field, danh sách project Jira.
  • Chỉ server được đặt: endpoint của Claude, Jira và Figma, lệnh MCP, webhook. HTTP redirect bị tắt.
  • Checks và test agent chạy code của repo trong container riêng qgate-runner (qua Unix socket trên volume qgate-work): không có secret, không mount /data, /config, /reviews, /repos, toolchains read-only, mạng bridge mặc định nên không gọi được dashboard. Mỗi scenario test có snapshot riêng. Chỉ watch repo bạn tin tưởng.
